# Support

## Where to ask

| Need | Channel |
| --- | --- |
| Usage question or design discussion | GitHub Discussions, if enabled; otherwise a clearly labelled issue |
| Reproducible defect | GitHub issue with version, environment, logs with secrets removed, and reproduction |
| Security vulnerability | Private process in [SECURITY.md](SECURITY.md) |
| Conduct incident | Confidential process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Production incident in your deployment | Your operator/on-call team using [the runbook](docs/RUNBOOK.md) |

Community support is best effort and has no response SLA. The latest tagged
release and current `main` are the supported code lines. Maintainers may close
requests that cannot be reproduced, omit required context, concern an old
version, or seek private deployment consulting.

Before filing, search existing issues and read [FAQ](docs/FAQ.md) and
[troubleshooting](docs/TROUBLESHOOTING.md). Never paste credentials, tokens,
private URLs, personal data, or unredacted logs.
